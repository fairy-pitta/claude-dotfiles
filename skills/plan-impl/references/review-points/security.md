# 設計観点: セキュリティ・認可

| 観点 | 設計段階での確認方法 |
|------|-------------------|
| **認可チェックの明示** | 新規エンドポイントに権限チェックが明示的に設定される設計か。デフォルト依存禁止 |
| **認可バイパス経路の排除** | エラーハンドリング不備により認可チェックがスキップされる経路がないか |
| **リソース所有権の検証** | 「操作者が権限を持つか」だけでなく「対象リソースが操作者のスコープに属するか」も検証する設計か |
| **機密フィールドの保護** | パスワード等の機密フィールドがAPIレスポンスに含まれない設計か |
| **冪等キーのスコープ** | 冪等制御のキーにユーザーIDを含め、ユーザー間で衝突しない設計か |
