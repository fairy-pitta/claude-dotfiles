# 設計観点: 型安全

| 観点 | 設計段階での確認方法 |
|------|-------------------|
| **具体的な型の使用** | any/unknown等の広すぎる型ではなく、具体的な型を使う設計か |
| **列挙値にEnum/定数** | ステータス値・カテゴリ値に文字列リテラルではなくEnum/定数を使う設計か |
| **型アサーションの回避** | 型キャスト(as)や非null断言(!)に頼らず、型ガードやデフォルト値で代替する設計か |
| **API境界での型変換** | 外部APIのレスポンスをそのまま使わず、内部ドメイン型に変換する設計か |
| **同一型の重複定義防止** | 既存の型と同等の構造を持つ型を別名で再定義していないか |
