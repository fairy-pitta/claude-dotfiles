# 設計観点: 状態管理（フロントエンド）

| 観点 | 設計段階での確認方法 |
|------|-------------------|
| **状態の分類** | サーバー状態・クライアントグローバル状態・ローカルUI状態が適切に分離されているか |
| **グローバル状態の読み取り専用公開** | グローバル状態が外部から直接書き込まれない設計か（readonlyラップ等） |
| **Propsの深い受け渡し防止** | 3階層以上のprops受け渡しが発生しない設計か |
| **状態のライフサイクル管理** | ページ遷移時やログアウト時に状態が適切にクリーンアップされる設計か |
| **キャッシュの無効化ポイント** | メモリキャッシュを導入する場合、認証境界で適切にクリアする設計か |
